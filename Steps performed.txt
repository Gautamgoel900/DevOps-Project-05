# Deploy Java Web App on Docker Container using Jenkins on AWS

## Complete Step-by-Step Guide

---

## Prerequisites

Before starting, make sure you have the following:

- [ ] An **AWS Account** with permissions to create EC2 instances
- [ ] A **Git/GitHub Account** with the source code repository

- [ ] Basic familiarity with **Docker** and **Git**

---

## Step 1: Setup Jenkins Server on AWS EC2 Instance

### 1.1 Launch an EC2 Instance

1. Log in to the **AWS Management Console**.
2. Open the **EC2 Dashboard** → Click **Launch Instance**.
3. Provide a **name** for the instance (e.g., `Jenkins-Server`).
4. Select **Amazon Linux 2 AMI**.
5. Choose instance type: **t2.micro** (free-tier eligible).
6. Select or create a **Key Pair** (`.pem` file) for SSH access.
7. Under **Network Settings**:
   - Use the **default VPC**.
   - Enable **Auto-assign public IP**.
   - Create a **new Security Group** with:
     - **SSH** (port 22) — Source: My IP or Anywhere
     - **Custom TCP** (port 8080) — Source: Anywhere (for Jenkins)
8. Click **Launch Instance**.

### 1.2 Connect to the EC2 Instance

1. Go to the EC2 instance → Click **Connect**.
2. Copy the **SSH command** from the SSH client tab.
3. Open your SSH client and connect using the public IP and `.pem` key.

### 1.3 Install Jenkins

1. Add the Jenkins repository:
   ```bash
   sudo wget -O /etc/yum.repos.d/jenkins.repo https://pkg.jenkins.io/redhat-stable/jenkins.repo
   ```

2. Import the Jenkins GPG key:
   ```bash
   sudo rpm --import https://pkg.jenkins.io/redhat-stable/jenkins.io-2023.key
   ```

3. Install EPEL packages:
   ```bash
   sudo amazon-linux-extras install epel -y
   ```

4. Install Java 11:
   ```bash
   sudo yum install java-11-openjdk -y
   ```

5. Verify Java installation:
   ```bash
   java -version
   ```

6. Install Jenkins:
   ```bash
   sudo yum install jenkins -y
   ```

7. Enable and start Jenkins:
   ```bash
   sudo systemctl enable jenkins
   sudo systemctl start jenkins
   ```

### 1.4 Access Jenkins Web UI

1. Open your browser and go to: `http://<EC2-Public-IP>:8080`
2. Retrieve the initial admin password:
   ```bash
   sudo cat /var/lib/jenkins/secrets/initialAdminPassword
   ```
3. Paste the password into the Jenkins unlock page.
4. Click **Install suggested plugins**.
5. Create your **first Admin user** (fill in username, password, full name, email).
6. Click **Save and Continue** → Jenkins is now ready!

## Step 2: Integrate GitHub with Jenkins

### 2.1 Install Git on the Jenkins EC2 Instance

```bash
sudo yum install git -y
```

Verify:
```bash
git --version
```

### 2.2 Install the GitHub Plugin in Jenkins

1. Go to **Jenkins Dashboard** → **Manage Jenkins** → **Manage Plugins**.
2. Click the **Available Plugins** tab.
3. Search for **GitHub Integration**.
4. Select the plugin and click **Install without restart**.

### 2.3 Configure Git in Jenkins

1. Go to **Manage Jenkins** → **Global Tool Configuration**.
2. Under **Git installations**:
   - Name: `Git`
   - Path to Git executable: `git` (Jenkins will auto-detect)
3. Click **Save**.

## Step 3: Integrate Maven with Jenkins

### 3.1 Install Maven on the Jenkins Server

> [!NOTE]
> Based on your environment, Maven **3.8.4** is already installed via `yum` at `/usr/share/maven`, and you are using **Java 17 (Amazon Corretto)**. You do NOT need to download Maven manually.

1. Install Maven (if not already installed):
   ```bash
   sudo yum install maven -y
   ```

2. Verify Maven:
   ```bash
   mvn --version
   ```
   Expected output:
   ```
   Apache Maven 3.8.4 (Red Hat 3.8.4-3.amzn2023.0.5)
   Maven home: /usr/share/maven
   Java version: 17.0.18, vendor: Amazon.com Inc.
   ```

### 3.2 Set Up Environment Variables

1. Go to the home directory and edit `.bash_profile`:
   ```bash
   cd ~
   vim .bash_profile
   ```

2. Add the following lines to `.bash_profile` **(use YOUR actual paths)**:
   ```bash
   JAVA_HOME=/usr/lib/jvm/java-17-amazon-corretto.x86_64
   M2=/usr/share/maven/bin
   M2_HOME=/usr/share/maven
   PATH=$PATH:$HOME/bin:$JAVA_HOME:$M2:$M2_HOME
   export PATH
   ```

3. Load the updated profile:
   ```bash
   source .bash_profile
   ```

4. Verify:
   ```bash
   echo $JAVA_HOME
   echo $M2_HOME
   mvn --version
   ```

### 3.3 Install Maven Plugin in Jenkins

1. Go to **Manage Jenkins** → **Manage Plugins** → **Available Plugins**.
2. Search for **Maven Integration**.
3. Select it and click **Install without restart**.

### 3.4 Configure Java and Maven Paths in Jenkins

> [!IMPORTANT]
> Use the paths from YOUR system, not the ones in the original README.

1. Go to **Manage Jenkins** → **Global Tool Configuration**.

2. **For Java (JDK):**
   - Name: `Java-17`
   - Uncheck "Install automatically"
   - JAVA_HOME: `/usr/lib/jvm/java-17-amazon-corretto.x86_64`

3. **For Maven:**
   - Name: `Maven-3.8`
   - Uncheck "Install automatically"
   - MAVEN_HOME: `/usr/share/maven`

4. Click **Save**.

## Step 4: Setup a Docker Host

### 4.1 Launch a New EC2 Instance for Docker

1. Launch another **Amazon Linux 2** EC2 instance (e.g., `Docker-Host`).
2. Use the same key pair as before.
3. Security Group: Allow **SSH (22)** and **Custom TCP (8081–9000)** from Anywhere.  

### 4.2 Install Docker

1. SSH into the new Docker Host instance.

2. Install Docker:
   ```bash
   sudo yum install docker -y
   ```

3. Verify Docker:
   ```bash
   docker --version
   ```

4. Enable and start Docker:
   ```bash
   sudo systemctl enable docker
   sudo systemctl start docker
   ```

### 4.3 Test with a Tomcat Container

1. Pull the official Tomcat image:
   ```bash
   sudo docker pull tomcat
   ```

2. Run a Tomcat container:
   ```bash
   sudo docker run -d --name tomcat-container -p 8081:8080 tomcat
   ```

3. Verify the running container:
   ```bash
   sudo docker ps
   ```

4. Access from your browser: `http://<Docker-Host-Public-IP>:8081`

> [!NOTE]
> You will likely see a **404 error**. This is a known issue — the `/webapps` directory is empty. The actual files are in `/webapps.dist`.

### 4.4 Fix the 404 Error (Manual Method)

1. Enter the running container:
   ```bash
   sudo docker exec -it tomcat-container /bin/bash
   ```

2. Copy the files:
   ```bash
   cp -R /usr/local/tomcat/webapps.dist/* /usr/local/tomcat/webapps/
   ```

3. Exit the container:
   ```bash
   exit
   ```

4. Refresh your browser — Tomcat should now display correctly.

### 4.5 Create a Custom Dockerfile (Recommended)

> [!TIP]
> Creating a custom Dockerfile avoids repeating the manual fix every time a new container is launched.

1. Create a `Dockerfile`:
   ```bash
   vi Dockerfile
   ```

2. Add the following content:
   ```dockerfile
   FROM tomcat:latest
   RUN cp -R /usr/local/tomcat/webapps.dist/* /usr/local/tomcat/webapps
   ```

3. Build the custom image:
   ```bash
   docker build -t tomcatserver .
   ```

4. Run a container from the custom image:
   ```bash
   docker run -d --name tomcat-server -p 8085:8080 tomcatserver
   ```

5. Access from browser: `http://<Docker-Host-Public-IP>:8085` — should work without errors.

## Step 5: Integrate Docker with Jenkins

### 5.1 Create a `dockeradmin` User on Docker Host

1. Create the user and set a password:
   ```bash
   sudo useradd dockeradmin
   sudo passwd dockeradmin
   ```

2. Add the user to the docker group:
   ```bash
   sudo usermod -aG docker dockeradmin
   ```

### 5.2 Enable Password-Based SSH Authentication

1. Edit the SSH config:
   ```bash
   sudo vim /etc/ssh/sshd_config
   ```

2. Make these changes:
   - **Uncomment**: `PasswordAuthentication yes`
   - **Comment out**: `PasswordAuthentication no`

3. Reload the SSH service:
   ```bash
   sudo service sshd reload
   ```

4. Verify by logging in as `dockeradmin`:
   ```bash
   ssh dockeradmin@<Docker-Host-IP>
   ```

### 5.3 Install "Publish Over SSH" Plugin in Jenkins

1. Go to **Manage Jenkins** → **Manage Plugins** → **Available Plugins**.
2. Search for **Publish Over SSH**.
3. Click **Install without restart**.

### 5.4 Configure Docker Host in Jenkins

1. Go to **Manage Jenkins** → **Configure System**.
2. Scroll down to the **Publish over SSH** section.
3. Click **Add** under SSH Servers and fill in:
   - **Name**: `Docker-Host`
   - **Hostname**: `<Docker-Host-Private-IP>` (or Public IP)
   - **Username**: `dockeradmin`
   - Under **Advanced** → check "Use password authentication" → enter the password
4. Click **Test Configuration** to verify connectivity.
5. Click **Apply** and **Save**.

> [!IMPORTANT]
> Using the **Private IP** for the hostname is recommended when both Jenkins and Docker Host are on the **same subnet/VPC**. You can also use the Public IP.

## Step 6: Create Jenkins Job to Build and Copy Artifacts

### 6.1 Create a New Jenkins Job

1. From the Jenkins Dashboard, click **New Item**.
2. Enter a name (e.g., `Deploy_on_Docker`).
3. Optionally, copy from an existing Maven build job.
4. Click **OK**.

### 6.2 Configure the Job

1. Update the **Description** as needed.
2. Under **Source Code Management**, select **Git** and provide your GitHub repository URL.
3. Under **Build Triggers**, enable **Poll SCM** (e.g., `* * * * *` for every minute).
4. Under **Build** → Root POM: `pom.xml`, Goals: `clean install`.
5. Under **Post-build Actions**:
   - Remove any previous post-build step.
   - Select **Send files or execute commands over SSH**.
   - **SSH Server**: Select `Docker-Host`.
   - **Source files**: `webapp/target/*.war`
   - **Remove prefix**: `webapp/target`
   - **Remote directory**: `/home/dockeradmin` (will change in Step 7)
6. Click **Apply** and **Save**.

### 6.3 Verify
                                                                                          ** disk space issue was faced as, adjusted by changing disk partion on jenkins server 
                                                                                                                           
- The build should trigger automatically (if Poll SCM is configured).
- Check **Console Output** to confirm success.
- SSH into the Docker Host and verify the `.war` file is present:
  ```bash
  ls /home/dockeradmin/
  ```

## Step 7: Update Dockerfile to Deploy the WAR File

### 7.1 Prepare the Directory on Docker Host

1. Create a docker directory under `/opt`:
   ```bash
   sudo mkdir /opt/docker
   ```

2. Change ownership to `dockeradmin`:
   ```bash
   sudo chown -R dockeradmin:dockeradmin /opt/docker
   ```

3. Move the Dockerfile to this directory:
   ```bash
   sudo mv Dockerfile /opt/docker/
   sudo chown -R dockeradmin:dockeradmin /opt/docker/
   ```

### 7.2 Update Jenkins Job Remote Directory

1. Go to the Jenkins Job → **Configure**.
2. Under **Post-build Actions** → **Send files or execute commands over SSH**:
   - Change **Remote directory** to: `//opt//docker`
3. Click **Apply** and **Save**.
4. Trigger a build and verify the `.war` file appears in `/opt/docker/`.

### 7.3 Update the Dockerfile

Edit the Dockerfile in `/opt/docker/`:
```dockerfile
FROM tomcat:latest
RUN cp -R /usr/local/tomcat/webapps.dist/* /usr/local/tomcat/webapps
COPY ./*.war /usr/local/tomcat/webapps
```

### 7.4 Manually Test the Deployment

1. Build a new Docker image:
   ```bash
   cd /opt/docker
   docker build -t tomcat:v1 .
   ```

2. Run a container:
   ```bash
   docker run -d --name tomcatv1 -p 8086:8080 tomcat:v1
   ```

3. Access from browser: `http://<Docker-Host-Public-IP>:8086/webapp/`

## Step 8: Automate Build and Deployment (Full CI/CD)

> [!IMPORTANT]
> This is the final step that ties everything together into a fully automated pipeline.

### 8.1 Add Exec Commands to Jenkins Job

1. Go to the Jenkins Job → **Configure**.
2. Under **Post-build Actions** → **Send files or execute commands over SSH**:
   - In the **Exec command** field, add:
     ```bash
    cd /opt/docker;
docker stop registerapp || true;
docker rm registerapp || true;
docker rmi regapp:v1 || true;
docker build -t regapp:v1 .;
docker run -d --name registerapp -p 8087:8080 regapp:v1
     ```
3. Click **Apply** and **Save**.

### 8.2 Test the Automation

1. Make a code change in your GitHub repository (e.g., edit the README or source code).
2. Commit and push the change.
3. Jenkins will automatically:
   - Detect the change (via Poll SCM)
   - Pull the latest code from GitHub
   - Build the project with Maven
   - Copy the `.war` artifact to the Docker Host via SSH
   - Build a new Docker image
   - Run a new container with the updated application
4. Access the deployed app: `http://<Docker-Host-Public-IP>:8087/webapp/`

## Summary of Architecture

```
GitHub (Source Code)
    │
    ▼  (Poll SCM / Webhook)
Jenkins Server (EC2)
    │  - Pulls code
    │  - Builds with Maven
    │  - Generates .war artifact
    │
    ▼  (Publish Over SSH)
Docker Host (EC2)
    │  - Receives .war file
    │  - Builds Docker image (Dockerfile)
    │  - Runs container with app
    │
    ▼
Tomcat Container (port 8087)
    └── Java Web App accessible via browser
```
